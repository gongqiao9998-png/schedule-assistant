# 行程助理 MVP

这是一个面向移动端优先的个人助理式日程管理原型，目标是把以下零散信息收拢成一个统一工作台：

- 邮件中的会议邀约
- 手机日历 / 提醒事项
- 临时约人见面与待办
- 钉钉中的差旅安排

当前版本先实现一条最小闭环：

1. 打开应用
2. 通过语音或文字输入一句自然语言
3. 系统自动拆出 `日程 + 提醒 + 待办 + 差旅预订请求`
4. 一键写入本地工作台

## 已实现

- 移动端优先界面
- 语音输入入口
- 自然语言时间解析
- 自动生成行事历卡片
- 自动生成提醒 / 待办
- 差旅预订请求占位
- 本地存储
- PWA 安装能力
- 在页面保持打开时的浏览器提醒

## 本地打开

直接打开 [index.html](./index.html) 可以查看界面。

如果希望更稳定地使用语音能力，建议在当前目录启动一个静态服务，例如：

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 发布到 Vercel

这个项目现在已经补好了 Vercel 部署配置文件 [vercel.json](./vercel.json)，可以直接按下面步骤发布：

### 方式一：用 Vercel 网页最省事

1. 把当前文件夹上传到 GitHub 仓库
2. 打开 [Vercel](https://vercel.com/)
3. 选择 `Add New Project`
4. 导入你的 GitHub 仓库
5. Framework 选择 `Other`
6. 不需要额外 build command
7. 直接点 `Deploy`

部署完成后，Vercel 会给你一个 HTTPS 地址，例如：

`https://your-app-name.vercel.app`

### 方式二：用 Vercel CLI

如果你本机已经安装 Node.js，可以在当前目录执行：

```bash
npm i -g vercel
vercel
```

首次执行会让你登录并确认项目设置，保持默认即可。

## 手机上安装

### iPhone

1. 用 `Safari` 打开 Vercel 部署后的网址
2. 点击底部 `分享`
3. 选择 `添加到主屏幕`
4. 桌面上就会出现“行程助理”

当前页面里也加了 `安装到手机` 按钮。

- 在 iPhone 上，它会提示你用 Safari 的“添加到主屏幕”
- 在 Android 上，如果浏览器支持，会直接触发安装提示

### Android

1. 用 `Chrome` 打开部署后的网址
2. 点击页面中的 `安装到手机`
3. 或者使用浏览器菜单中的 `安装应用 / 添加到主屏幕`

## 适合当前阶段的使用方式

这版最适合先做：

- 手机上的语音录入体验验证
- 日程自动整理流程验证
- 和你自己的真实工作流一起跑一段时间

等你确认核心流程顺手后，再继续做：

- 邮箱同步
- 系统日历写入
- 原生通知
- 差旅平台对接

## 当前限制

- 邮件、手机日历、提醒事项、钉钉差旅还没有接真实接口
- 浏览器版提醒只能在页面保持打开或浏览器允许通知时生效
- 自然语言抽取目前是前端规则版，适合做 MVP 演示

## 助理收件后端骨架

当前版本已经补上第一层真实后端骨架，适合先验证：

- 助理收件设置表单是否能走真实 `/api`
- IMAP 收件服务器是否可连通
- 当前邮箱里最近的 `[助理]` 标识邮件是否能被找到

已新增的接口：

- `POST /api/mailbox/settings`
- `POST /api/mailbox/test-connection`
- `POST /api/mailbox/check-tagged-mails`
- `POST /api/mail/check-latest`

当前这层后端能力的定位是：

1. 校验邮箱配置参数
2. 测试 IMAP 服务器连通性与登录
3. 在支持该要求的邮箱上带上 `IMAP ID` 客户端身份声明
4. 打开指定文件夹
5. 读取最近邮件头并筛选主题含 `[助理]` 的邮件

这版还没有完成的部分：

- 服务端持久化保存邮箱配置
- 读取整封原始邮件正文
- 自动提取 `.ics`
- 根据 `UID / METHOD / STATUS` 自动判断新增、改期、取消
- 数据库存储导入结果

因此，这一版更准确地说是：

`真实邮箱检查的后端骨架 + 仍保留前端导入演示`

## 建议下一步

### 1. 接入真实 AI 抽取

将 `app.js` 中的 `parseAssistantInput()` 替换为服务端接口：

- 语音转写：Whisper 或移动端语音 SDK
- 结构化抽取：LLM 输出 JSON 草稿
- 多来源归并：邮件、日历、提醒事项、钉钉消息统一入库

### 2. 接入真实系统

- 邮件：Outlook / Exchange / Gmail API 读取会议邀约
- 日历：iOS / Android 系统日历读写
- 提醒：系统提醒事项或企业 IM 待办
- 差旅：钉钉审批 / 企业差旅平台 API

### 3. 升级成正式移动应用

推荐技术方向：

- `Flutter`：适合快速做跨端语音、通知和日历能力
- `React Native + Expo`：适合接 AI 能力和快速迭代
- `PWA + 后端服务`：适合先演示流程、快速验证需求
